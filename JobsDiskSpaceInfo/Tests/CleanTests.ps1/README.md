# `CleanTests.ps1` 隔离验证

从本目录运行 `powershell.exe -NoLogo -NoProfile -File ./CleanTests.ps1`；跨平台核心夹具可用 `pwsh`。测试只在本轮新建的系统临时目录构造假用户目录、缓存、历史、默认 AVD 登记、Flutter runner 与 APK / AAB 输出，不执行真实用户清理、安装、菜单注册、工具下载或 VM 控制。

覆盖预览 / 取消、常规与开发分组互斥、空选及首行全组 ID 解析、精确部分选择、清单变化、备份失败、暂存后失败恢复、缺失目标重新出现、严格工程白名单、重解析父链和外部目标保留；删除失败夹具核对具体异常原因及目标路径同时输出至终端信息流与日志。常规失败重试覆盖多轮失败后成功、成功项出队、新候选排除、非空 / 空格 / EOF 停止、永久失败再次询问、原快照复检、取消传播和同一纯文本日志追加。不能创建真实符号链接时单列跳过。键盘状态机通过注入键序列验证，不能替代 Windows 控制台和 `fzf` 的真实交互。

开发阶段额外覆盖最终范围回车执行、非空 / 空格取消阶段、EOF 停止、普通失败立即返回常规及取消异常传播；两阶段编排使用假开发业务和常规业务，核对开发失败后常规仍执行、常规成功不覆盖开发失败、EOF / 取消不进入常规。Ctrl+C 的管道停止异常在独立 runspace 中核对传播，避免中断测试宿主。跨平台核心隔离验证不代表原生 Windows 控制台与真实菜单已验收。

通用保护夹具使用随机用户和环境目录名，覆盖 Go／Node／Rust／Python／Flutter／Android SDK 等十种标准清单标记、只读内容在计划阶段整项保留、普通过期缓存仍可明确清理、条目／深度／时间预算超限保留，以及确认后新增开发标记阻止执行。目录挂载点沿 Windows 重解析点边界处理，现有链接夹具核对外部实体不变。

询问展示夹具精确核对青／绿／红粗体及分隔符复位、无选项询问、NO_COLOR存在含空值、非TTY、纯文本与未知宿主／VT能力的降级。实际开发首问、最终确认、原生菜单标题和失败重试均覆盖；读取和取消结果保持原语义，询问日志不含ANSI。这里验证的是格式及能力分支，未把跨平台字符串断言写成原生Windows控制台的实际视觉验收。

生产清理入口为 [Clean.ps1](../../Scripts/Clean.ps1/Clean.ps1)，测试使用点载入，仅加载函数，真实删除仅发生于临时夹具。阶段编排的业务函数均拦截，不运行真实用户清理。测试结束只移除本轮唯一创建的临时夹具目录。

缓存选择使用隔离子进程验证全选／跳过行顺序、完整候选展开、冲突跳过优先、空输出与失败输出拒绝；核对开发组与缓存组均使用 `space:accept-non-empty`，避免零勾选时抑制当前行及有勾选时追加光标项。不执行真实 fzf 控制台或用户清理。
