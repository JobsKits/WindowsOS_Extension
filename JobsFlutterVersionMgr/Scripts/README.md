## 🔥 <span id="前言">前言</span>

本目录是 [JobsFlutterVersionMgr](../README.md) 的自包含运行与安装源码。安装从包根的 [`Manage.cmd`](../Manage.cmd) 开始，卸载使用 [`Manage.cmd`](../Manage.cmd)；右键操作由已部署的 `Invoke.ps1` 在可见终端启动。不要把本目录拆散后单独分发。

| 文件 | 职责 |
| --- | --- |
| [Manage.ps1](./Manage.ps1) | 检查 Windows PowerShell 5.1 与 STA，确认后仅管理本包菜单。 |
| [PackageInstaller.psm1](./PackageInstaller.psm1) | 复制及校验本包运行文件、当前用户菜单注册、备份、状态事务与卸载。 |
| [Common.psm1](./Common.psm1) | 本包内嵌的路径、参数、进程及日志基础工具。 |
| [Invoke.ps1](./Invoke.ps1) | 校验本包启用状态，加载本包 Action，报告失败并保留终端。 |
| [Action.psm1](./Action.psm1) | 严格项目门禁、条件修复工具链、官方版本查询、fzf 单选、备份和精确项目 SDK 绑定。 |

安装器复制直属 `.ps1` / `.psm1` 进入独立 release，测试不会打包；运行时不读取总目录或相邻包。四份基础设施模块与仓库模板保持一致，业务入口是 `Action.psm1`，SDK 实时输出由同目录 `SdkDownloadOutput.ps1` 辅助。

项目门禁首先运行，非法目标不会触发依赖安装。健康 Git / fzf / FVM 直接复用；缺 Git / fzf 时才检查 WinGet。必需组件安装回车执行、任意字符取消；最终项目操作同样直接回车执行安装/切换、任意非空输入取消，空格也会取消。Esc 选版取消不修改项目。

本包菜单安装不联网、不提权；业务工具安装和未缓存 SDK 下载会联网，并分别显示来源、范围与确认。PATH 与 TLS 1.2 补充只作用当前进程，退出后恢复；不修改网络代理或系统开发者模式。具体 SDK 来源服从 FVM 现有配置。

状态、私有工具、业务日志和备份位于当前用户本地应用数据的 `Jobs\WindowsExtension\extensions\flutter-version-manager`。切换前在项目外备份配置，既有 SDK 链接只记录目标；失败现场与已下载 SDK 保留。恢复方法、版本与权限限制见[包说明](../README.md#四文件日志与恢复)。

测试入口位于仓库 [`Tests/FlutterVersionMgr.Tests.ps1`](../../Tests/FlutterVersionMgr.Tests.ps1)，仅使用隔离夹具；Windows 真实菜单和 SDK 安装需单独验收。

本目录的 `Manage.ps1`、`SelectionPanel.psm1` 和 `ManagementWorker.ps1` 构成本包自包含管理面板；由上级 `Manage.vbs` 无控制台启动。安装 / 卸载在隐藏后台执行，逐项状态与可复制实时日志留在面板中。日志区上沿的分隔条可上下拖动，调节结果在当前窗口保留；上下限为功能行、操作按钮和日志工具栏留出空间。日志正文右键可“复制”或“全选”，也支持 Ctrl+A / Ctrl+C；全选仅针对当前可见缓冲区，完整输出使用“复制全部日志”。总进度按已处理项 / 本次所选项显示计数和百分比；成功、未安装无需卸载与失败计入已处理，等待中、执行中和未执行项不计入；“未安装，无需卸载”单独显示且不算成功，最终分别汇总成功、无需卸载、失败与未执行数量。100% 仅表示本轮全部处理完毕。安装 / 更新和卸载分别计时；点击时只清零并启动当前操作计时，后台全部结束或启动失败时只冻结当前耗时。每秒刷新 `HH:mm:ss`（小时可超过 24），执行时显示“安装用时 / 卸载用时”，结束显示“安装总用时 / 卸载总用时”。两份耗时只在当前面板会话内独立保留。安装成功显示绿色“✅ 安装成功”。不改变右键业务工具自己的交互方式。失败状态可点击，在独立 PowerShell 中只读显示本次完整会话日志；包失败不阻止其它所选包，日志不可用时在面板提示。

**SDK 初始化进度：** 随包的 [SdkDownloadOutput.ps1](./SdkDownloadOutput.ps1) 实时展示 SDK 相关命令输出，保留机器响应、退出码和超时边界；第一次调用 Flutter 触发 Dart / 工具缓存下载时，不再等待命令结束才显示。FVM 安装 / 切换保留原生控制台进度，下载 FVM 工具包时显示真实接收字节与速度。PubGet 的 URL / 认证信息继续脱敏后显示和落盘；测试不接触真实 SDK、账户缓存或系统菜单。

**SDK 环境准备：** 已选择的 SDK／版本所需下载、安装及首次 Flutter／Dart 缓存补齐自动执行；网络失败或无进度超时后持续重试，间隔逐步增加并封顶 30 秒，没有次数和总时长上限，直到成功或本人 Ctrl+C／停止。仍在输出下载进度的传输不按总时长截断；成功后才进入后续业务。目标／版本选择、官方许可证与系统权限仍由本人处理；路径、权限、磁盘或明确不存在的版本会报告具体原因。每次尝试和真实进度追加到终端所示日志；同一 URL 有 ETag／Last-Modified 时安全续传，跨来源保留独立临时文件，不拼接不同来源。失败／取消保留下载现场；业务构建和配置写入不因网络重试而整体重放。

**Flutter SDK网络预检：** 下载／首次Dart自举／precache前，随包网络模块以真实小Range验证来源、TLS、字节和吞吐并择优；显式storage、Pub和代理（含空值）保留，AUTO仅核验官方／CFUG同对象及当前已配置代理，不猜端口、不改系统代理或Git。当前任务短期复用；真实获取失败会降权坏路线、轮换其它已验证候选并持续重试。FVM按实际api context来源处理，能力允许时Git与Dart制品分阶段；用户fork不改源。原生BITS按真实WinINET通道衡量，PAC未能有界解析时保留既有通道并明确未测速。详细边界见[随包选路模块](./SdkDownloadRoute.ps1/README.md)。
