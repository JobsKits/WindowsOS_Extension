# 一键提取与导入 Flutter 依赖

[FlutterDependencyMigration.psm1](./FlutterDependencyMigration.psm1) 由统一菜单的 `export-all-dependencies` / `import-all-dependencies` 调用；依赖本包上级目录中的 Dart 引擎和已有健康的原生 Dart，优先项目 FVM。不能单独复制此文件夹作为完整工具包，应整体携带 `JobsFlutterTools`。

扫描和导入期间显示当前阶段及累计耗时，例如：

```text
扫描并校验导入计划｜已耗时 00:00:10；请稍候，Ctrl+C 取消。
扫描并校验导入计划｜完成｜总用时 00:00:12
```

阶段开始立即提示；可交互控制台每秒原位刷新 `HH:mm:ss`，重定向、`NO_COLOR`、`TERM=dumb` 或 `PLAIN_OUTPUT=1` 时每 10 秒输出完整心跳行。小时累计超过一天不会归零。预检、策略重算和确认后的导入各自计时；选择了备份时显示“校验、备份并导入依赖”。确认与选择期间停止刷新，完成、失败或取消后收尾并输出本阶段总用时。计时表示实际经过的时间，不估算百分比或剩余时间；它不能证明磁盘操作没有阻塞。失败仍保留真实退出码与错误，超时或可捕获的取消仅停止本轮启动的进程树，不自动回滚已完成写入。

- 一键提取先说明私库范围。直接回车只提取可识别的私库候选；输入任意字符（包含空格）再回车，才进行全提取。Git、本地 path 和非公共源属于私库候选，不能据此证明仓库访问权限；缺少来源证据的原生缓存会列为缺口。
- 输出父目录可输入或拖入，回车为系统桌面。引擎成功后，回车打包 ZIP、非空不打包；ZIP 完成逐文件 SHA-256 核对后，回车保留提取目录、非空删除。只允许删除本次新建的直属产物；ZIP 损坏、源文件变化或链接会停止删除。
- 一键导入可选迁移产物、原始 Pub / Gradle 缓存，或包含这些目录的父目录。目录名称允许变化，由引擎检查内容；ZIP 先解压。空输入持续询问，输入结束或 Ctrl+C 取消。先只读预检；普通文件内容冲突提供 fzf 二选一，默认首项“使用导入源（推荐）”覆盖，另一项“保留本机现有内容”跳过冲突但继续融合其它文件。缺少或损坏 fzf 时回退编号：回车或 `1` 使用导入源，`2` 保留本机，`q`、Esc、Ctrl+C 或输入结束取消。选择覆盖后，确认问句用默认文字色，“回车 = 备份”用绿色，“任意字符再回车 = 不备份直接覆盖：”用红色；`NO_COLOR`、`TERM=dumb` 或非交互时用纯文本。回车默认先备份；输入任意非空字符（包括空格）再回车表示不备份。备份父目录支持输入或拖入，空回车默认系统桌面；交互和预检不提前创建目录。引擎按选定策略重算计划，最终确认处空回车只继续询问，不融合、不重新生成计划；只有精确大写 `YES` 才融合并再次核对本次源与目标。其它非空输入、输入结束或 Ctrl+C 取消。
- 已由工具导入且包声明有效的 vendor 覆盖保留当前版本和路径，计划逐包显示当前与快照版本，只新增尚未覆盖的快照包及缺失缓存；全包保留时不新建 vendor 目录或修改覆盖配置。缺少工具记录、路径失效、自定义覆盖仍拒绝；此流程不修复既有包内部损坏文件。
- 缓存目标从当前 `PUB_CACHE` / `GRADLE_USER_HOME` 或当前系统默认目录解析；不沿用原机绝对路径。已知认证配置、用户配置、init 脚本、运行锁和 daemon 数据不作为迁移载荷。
- Gradle 原始缓存与全量提取保留 `metadata-*/descriptors` 模块描述，排除共享可变 `.bin` 索引和 `gc.properties`。制品已导入不等于解析记录完整或完全离线；工程将 SNAPSHOT 缓存时间设为 0 时，正常构建仍会请求原仓库校验元数据，仓库不可达须另行处理，不能只靠重复导入保证运行。
- 不下载依赖、不执行项目或包内脚本、不安装 SDK、不修改全局 Flutter/Java。迁移材料不保证完整离线构建；公共库、FVM/Flutter、Java、Android SDK、Apple 工具链、鸿蒙工具链和私库认证须按目标平台另行准备。
- 运行日志为系统临时目录中的 `JobsFlutterMigration-*.log`，来源地址脱敏。Windows 的 ZIP 使用 .NET 压缩流，包含隐藏文件，并检查实际解压数据；不会调用会跳过隐藏文件的通用压缩命令。

隔离验证入口：`pwsh -NoProfile -File ../../../Tests/FlutterDependencyMigration.Tests.ps1/FlutterDependencyMigration.Tests.ps1`。该测试覆盖终端选择、实际菜单分发、fzf 默认与取消、编号回退、覆盖备份选择、保留本机策略、计划绑定、真实 ZIP 校验和删除范围，以及静默进程逐秒计时、纯文本心跳、双流大输出、非零退出、启动失败、超时和 PowerShell 管道取消的真实子进程清理；来自 MacOS 上的 PowerShell 7 时，不代表 Windows PowerShell 5.1、Explorer 或真实用户缓存已经验收。

迁移快照保留工程声明和锁文件，可能包含私有地址或开发机路径；自行写在源码、声明中的敏感内容不能依靠缓存文件名过滤消除，跨人分享前应检查产物。导入使用选定策略的预检计划指纹绑定本次源文件与目标状态，确认期间发生变化会停止。选择保留本机时不会创建覆盖备份；选择备份覆盖时，最终确认后在所选父目录新建唯一子目录，核验旧文件备份后才覆盖，并显示实际备份位置。备份失败停止覆盖，取消、输入结束或非空且非 `YES` 不写依赖或备份。目录与文件类型冲突、链接及自定义工程覆盖等不可安全融合项仍拒绝，不能用内容冲突策略绕过。

仅一键文件迁移允许在项目 FVM Dart 不可用时复用已有健康的原生系统 `dart.exe`；系统 Flutter 的 `dart.bat` 只用于定位旁边已安装的 `cache/dart-sdk/bin/dart.exe`，不执行 shim，不下载或切换项目 SDK。普通 Pub 提取 / 导入保持原有项目 FVM 约束。
